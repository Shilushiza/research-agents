# Скиллы стека research-agents

Всё, что лежит здесь, Claude Code видит автоматически при запуске из `D:\research-agents`.
Вызов — по описанию (агент сам подхватит) или явно через `/<имя>`.

## Ресёрч

| Скилл | Для чего | Источник |
|---|---|---|
| **deep-research** | широкая разведка по задаче: обзор области, статьи, репо, соседние подходы → отчёт со ссылками | локальный (заточен под этот стек) |
| **arxiv-mcp-server** | поиск/чтение/мониторинг статей arXiv, секции из LaTeX, граф цитирований | [blazickjp/arxiv-mcp-server](https://github.com/blazickjp/arxiv-mcp-server) |

## Экономия контекста (доклад: «сжимать нужно не только переписку»)

| Скилл | Для чего | Источник |
|---|---|---|
| **caveman** | режим ультра-сжатого ответа без потери сути (`/caveman lite\|full\|ultra`) | [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman) |
| **caveman-compress** | сжать CLAUDE.md / todo / память в caveman-формат, бэкап отдельно | там же |
| **caveman-explore** | read-only обзор репозитория с холодного старта, цитаты `path:line`, чтение не течёт в главный контекст | там же |
| **cavecrew** | делегировать поиск/правку/ревью суб-агентам со сжатым выводом | там же |
| **caveman-stats** ⚠️ | токены и экономия за сессию из лога | там же |
| **caveman-learn** ⚠️ | применить отчёт caveman о дорогих местах | там же (нужен Caveman Cloud) |

## Качество кода (доклад: Sentrux + «правила сопровождения кода»)

| Скилл | Для чего |
|---|---|
| **investigate-first** | диагностика неясных сбоев до правок, гипотезы по силе доказательств |
| **lean-build** | новая фича с риском переусложнения: строгий скоуп + условие остановки |
| **surgical-patch** | фикс бага на самом узком слое, с тестом |
| **safe-refactor** | реструктуризация без изменения поведения, проверки до и после |
| **migration** | обратимые переходы: схема, данные, API, конфиг, зависимости |
| **verify-and-stop** | доказать, что готовое соответствует критериям, без расширения скоупа |
| **caveman-review** | компактное код-ревью: строка на находку (место · проблема · фикс) |
| **caveman-commit** | Conventional Commits, сжато до сути |

## Сборка своих инструментов

| Скилл | Для чего | Источник |
|---|---|---|
| **skill-creator** | создать/улучшить/протестировать скилл (процедура с входами, выходами, проверками) | [anthropics/skills](https://github.com/anthropics/skills) |
| **mcp-builder** | собрать качественный MCP-сервер (Python/TS) под внешний API | там же |

## Только с аккаунтом Caveman Cloud ⚠️

`caveman-discover`, `caveman-setup`, `caveman-manage`, `caveman-optimize`, `caveman-evidence-review`
— завязаны на платный шлюз Caveman Cloud. Оставлены для полноты; без аккаунта не сработают.

## Сделать глобально доступными (из любой папки)

Скопировать нужные в `C:\Users\ydtsv\.claude\skills\`, либо подключить всю папку как
маркетплейс плагинов:

```
/plugin marketplace add D:\research-agents
/plugin install research-agents@research-agents
```
